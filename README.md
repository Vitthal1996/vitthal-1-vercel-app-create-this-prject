## 🚀 Features

- **Cinematic Sparkles Preloader**: Dynamic HTML5 Canvas particle intro with smooth morph transition.
- **Interactive Case Studies**: Detailed breakdowns with research, user personas, information architecture, wireframes, and design system highlights.
  - **Illuminati**: Enterprise-grade UI/UX workflow & platform
  - **CareConnect**: Telehealth & healthcare management application
  - **GlobiCall**: International roaming & VoIP communication application
  - **Physio**: Physical therapy & rehabilitation tracking
  - **QuikJob**: Fast-track job marketplace & applicant tracking
  - **RawFitness**: Fitness & personal training club platform
  - **FXTM**: Financial trading & market analysis tool
- **Interactive Mockup Modals**: Full-screen high-resolution case study viewer with tab navigation.
- **Custom Cursor & Micro-Interactions**: Magnetic buttons, particle trails, and responsive hover states.
- **Mobile Responsive**: Fully responsive layout designed with standard mobile-first practices.

## 📁 Project Structure

```
├── index.html                 # Main entry point & portfolio layout
├── styles.css                 # Custom styling, animations, and design system tokens
├── projects-data.js           # Case study metadata, metrics, and content
├── mockups.js                 # High-resolution interactive mockup components
├── illustrations.js           # SVG graphics, icons, and illustrations
├── app.js                     # Core portfolio logic, filters, and modal controllers
├── cursor.js                  # Custom cursor & magnetic interactions
├── preloader.js               # Canvas particle animation and cinematic intro
└── *.png                      # Project assets, case studies, and UI mockups
```

## 💻 Local Development

You can run this project locally with any static web server:

### Python 3
```bash
python3 -m http.server 3000
```

### Node.js (npx serve)
```bash
npx serve .
```

Then open `http://localhost:3000` in your browser.
